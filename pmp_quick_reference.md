# PMP Quick Reference Card 📚

## 🎯 INSTANT RECALL FORMULAS

### EVM Essentials:
```
CPI = EV ÷ AC    (Cost Performance)
SPI = EV ÷ PV    (Schedule Performance)
EAC = BAC ÷ CPI  (Estimate at Completion)
ETC = EAC - AC   (Estimate to Complete)

> 1.0 = GOOD (under budget/ahead)
< 1.0 = BAD (over budget/behind)
= 1.0 = PERFECT (on target)
```

### Communication Channels:
```
n × (n-1) ÷ 2
Where n = number of people
```

## 🚦 DECISION TREES

### Contract Selection:
```
Scope Clear? → YES → Fixed Price
             ↓ NO
Requirements Change? → YES → Cost Plus
                     ↓ NO
                     Time & Materials
```

### Leadership Style:
```
Team Experience?
├─ Low → Autocratic
├─ Medium → Democratic  
└─ High → Laissez-faire

Special Cases:
├─ Crisis → Autocratic
├─ Agile → Servant Leader
├─ Change → Transformational
└─ Routine → Transactional
```

### Risk Response:
```
Negative Risks: Avoid, Transfer, Mitigate, Accept
Positive Risks: Exploit, Share, Enhance, Accept
```

## ⚡ INSTANT RECOGNITION

### Assumptions vs Constraints:
```
ASSUMPTION = "We believe..." | "We think..." | "Probably..."
CONSTRAINT = "Must..." | "Cannot..." | "Required..."

False Assumption = NEGATIVE
False Constraint = POSITIVE
```

### EEFs vs OPAs:
```
EEF = Can't Control (External/Environmental)
OPA = Can Use (Organizational assets)

Test: "Can I change this?"
NO → EEF | YES → OPA
```

### Agile Triangle:
```
Traditional: Fixed Scope | Variable Time/Cost
Agile: Fixed Time/Cost | Variable Scope
```

```

"How can I help?" → Servant Leader
"Do this, get that" → Transactional
"Change the world!" → Transformational
```

## 📊 EVM HEALTH CHECK

```
CPI = 1.2, SPI = 0.8 → Under budget, Behind schedule
CPI = 0.9, SPI = 1.1 → Over budget, Ahead of schedule
CPI = 1.0, SPI = 1.0 → Perfect health
```

## 🔄 COMMON PATTERNS

### Planning Poker Steps:
1. Read story
2. Discuss & ask questions
3. Pick cards privately
4. Reveal simultaneously
5. **If different:** Discuss reasons
6. Re-estimate
7. Repeat until consensus

### Sprint Rejection Process:
1. Determine why rejected
2. Rewrite user story
3. Place back in backlog
4. Reprioritize

## ⚠️ WATCH OUT FOR

### Tricky Words:
- **Workaround** = Unplanned response to unidentified risk
- **Milestone** = Zero duration
- **Lag** = Waiting time
- **Float/Slack** = Delay without impact

### Ethics Guidelines:
- Always cooperate with investigations
- Report violations after giving chance to correct
- Never accept inappropriate gifts (unless local custom)
- Disclose conflicts of interest
